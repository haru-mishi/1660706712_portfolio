Thai Digit Recognition

Solo rebuild of a 10-class digit CNN (~92% accuracy) served through a Flask API. Freehand strokes are segmented and composed into multi-digit numbers of any length; an explicit stroke-boundary signal resolves touching digits that proximity-based heuristics can't disambiguate.

Haru AI Hub

Each API key is restricted to an allow-list of models, and chat talks to a local Ollama instance through a swappable model reference rather than a hardcoded one.

KFSuay POS

A FastAPI + Postgres backend slice proving concurrent orders can't oversell shared stock: a SELECT ... FOR UPDATE row lock serializes contention on the order endpoint, so 30 simultaneous requests against 10 units of stock resolve to exactly 10 accepted and 20 cleanly rejected — never negative, never double-sold. Wrapped in a small register-style demo UI (cart, QR receipt) with the stress test tucked behind a hidden control, since the lock is the point, not the ordering flow.
